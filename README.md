# smerticariu/tap

Homebrew casks for my apps.

```sh
brew install --cask smerticariu/tap/my-terminal
```

| Cask | App |
|---|---|
| `my-terminal` | [My Terminal](https://smerticariu.github.io/my-terminal/), a native macOS terminal with command blocks. Nothing typed or printed in it leaves the Mac. |

Update with `brew upgrade --cask my-terminal`.
